# docs/decisions/

Lightweight Architecture/Operating Decision Records (ADRs).

Naming: `<yyyy-mm-dd>-<short-topic>.md`.

Template (keep short):

```
# Decision: <title>
Date: <yyyy-mm-dd> · Status: proposed | accepted | superseded
## Context
## Decision
## Consequences
## Alternatives considered
```

Use for choices that future agents must not silently reverse (branch model, billing gates, deployment ownership, etc.).
