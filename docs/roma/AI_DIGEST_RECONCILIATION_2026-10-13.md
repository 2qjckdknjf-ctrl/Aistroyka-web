## Agent Handoff Checkpoint

Детализация GROW-RUNTIME-002 / GROW-SCHEDULER-004 / GROW-MEM-004, P0 contract; P1 resume implementation после identity/guard/budget. Versioned task/attempt/checkpoint contains objective/remaining AC, repository/ref/HEAD/write set, verified artifacts/checks/source times, failed approaches, unresolved blockers, next allowed step, model/tool/skill/context versions, used/remaining budget и pending side-effect reconciliation. Secrets/hidden evaluator answers не сохранять. Memory OS хранит scoped evidence/state refs; task execution lease/state остаётся runtime responsibility.

New worker rechecks owner/principal grants, revoke/expiry/policy, HEAD/artifact freshness, resource identity, budget and lease. Старый checkpoint не расширяет authority. AC: crash before/after tool effect, repeated resume, changed HEAD, stale grant, duplicate event, no-progress loop, STOP and unavailable infrastructure; exactly one logical effect or explicit reconciliation, never fake completed task.

## Skill Effectiveness и workflow optimization

Расширение GROW-MODEL-ARENA-001 / ROMA-CORPUS-004 / ROMA-CAP-001. P0 admission condition для автоматически выбранного skill, P1 offline slice. 3–5 existing skills: skill vs no-skill vs placebo on same tasks/config/budget and independent hidden rubric; randomized order/repeated runs, all failures, uncertainty and cost. Skill promoted only for measured applicable class, no blanket claim. Registry stores version, useful task classes, effect size/limitations.

MASS-inspired optimization P2 experiment после baseline: менять только разрешённые worker order/context/parameter range; verifier/risk/policy/hidden tests frozen. Baseline→candidate→independent holdout→reviewed promotion→rollback. Trial/compute/no-progress caps and failed runs ledger mandatory; no self-learning live model. Domain small-model bake-off (work/unit classification, defect/report class, HiAir explanation template) uses same framework with privacy/minimum-quality baseline.

Muse Wonder/Mellum/Jebadiah/EmbeddingGemma/Clef-omni and other names из обзоров остаются candidate shortlist. API availability/version/license/local fit/data policy сначала; недоступный candidate skipped with reason, не объявлять integration DONE. MXC/Aperture/LangChain/Agent Lightning/OpenClaw — timeboxed build-vs-adopt references, не обязательные dependencies.

## Дополнения из ранних недельных обзоров

- **GROW-AUDIT-007 / ROMA-VER-009 — Code Graph / Dependency Graph**, P1 после current assurance contracts; P0 coverage prerequisite для risk-based selective tests. Repository AST/files/functions/imports/routes/API/schema/migrations/tests + explicit uncertain edges; incremental revision/SHA, deleted symbols, dynamic imports and unknown dependency→conservative revalidation. Impacted requirement/test paths shown with evidence; graph indexes code, не customer records. Не создавать отдельную Construction Graph вместо engineering graph.
- **ROMA-CAP-001 / ROMA-PACKAGE-001 — Document to Skill compiler**, P2 after trusted registry/sandbox. Paper/document→source-linked proposed skill/schema/preconditions/tests→human/security/license review→versioned package. Extracted instructions untrusted; generated code не executes at ingest, no grant of new permissions. Skill bake-off/hidden eval and digest revalidation before admission.
- **ROMA-OBS-001 — Automation Index / AI Adoption Analytics**, P1 after ledger. Measure eligible scoped tasks, verified completion, retries/rework, human intervention, cost/time/incident/stale evidence; define denominator and label historical/unknown data. Successful low-risk tasks не автоматически raise autonomy/permissions; ROI requires actual baseline and observed outcomes.
- **GROW-RETRIEVAL-011 / GROW-MEM-004 — Context Runtime**, P1: progressive disclosure and task-bound response projection, source authority/freshness/ACL before model context. Source maps to artifacts/tests/dependencies/decisions; budget/truncation explicitly surfaced. Candidate lesson memory cannot override current code or signed policy.
