# Changes

All changes are confined to `android/**` Gradle config + `.gitignore` hygiene.
No application source (Kotlin/Compose) logic was changed.

## 1. Toolchain upgrade (required for compileSdk 35)

`compileSdk 35` requires AGP ≥ 8.6 and Gradle ≥ 8.7.

| File | Before | After |
| --- | --- | --- |
| `android/gradle/wrapper/gradle-wrapper.properties` | `gradle-8.2-bin.zip` | `gradle-8.7-bin.zip` |
| `android/build.gradle.kts` | AGP `8.2.2` | AGP `8.6.1` |

Kotlin remains `1.9.20`; Compose compiler ext remains `1.5.5`; JDK 17.

## 2. SDK 35 bump

| Module | compileSdk | targetSdk | minSdk (unchanged) |
| --- | --- | --- | --- |
| `:AiStroykaManager` | 34 → **35** | 34 → **35** | 26 |
| `:AiStroykaWorker` | 34 → **35** | 34 → **35** | 26 |
| `:shared` | 34 → **35** | n/a (library) | 26 |

Application IDs unchanged: `ai.aistroyka.manager`, `ai.aistroyka.worker`.

## 3. Release signing wired (no secrets committed)

Both app modules now load `android/keystore.properties` (gitignored) and define a
`release` signingConfig **only when** the keystore + all required properties are
present. When absent (e.g. CI without secrets), the release build remains unsigned —
identical to prior behavior — so CI is not broken.

```kotlin
val keystoreProperties = Properties().apply {
    val keystorePropertiesFile = rootProject.file("keystore.properties")
    if (keystorePropertiesFile.exists()) keystorePropertiesFile.inputStream().use(::load)
}
val releaseStoreFile = keystoreProperties.getProperty("storeFile")?.let { rootProject.file(it) }
val hasReleaseSigning = releaseStoreFile?.exists() == true &&
    !keystoreProperties.getProperty("storePassword").isNullOrBlank() &&
    !keystoreProperties.getProperty("keyAlias").isNullOrBlank() &&
    !keystoreProperties.getProperty("keyPassword").isNullOrBlank()
// signingConfigs { if (hasReleaseSigning) create("release") { ... } }
// buildTypes { getByName("release") { if (hasReleaseSigning) signingConfig = signingConfigs.getByName("release") } }
```

## 4. Safe versionCode override

Hard-coded `versionCode = 1` replaced with an override-able resolver. Local/dev
builds default to `1`; store/CI builds set `AISTROYKA_ANDROID_VERSION_CODE` (Gradle
property or env var) without editing source. `versionName` stays `1.0.0`.

```kotlin
val resolvedVersionCode =
    (providers.gradleProperty("AISTROYKA_ANDROID_VERSION_CODE").orNull
        ?: providers.environmentVariable("AISTROYKA_ANDROID_VERSION_CODE").orNull)
        ?.trim()?.toIntOrNull() ?: 1
```

## 5. `.gitignore` hardening

Added rules so signing materials and build artifacts can never be committed
(they were previously NOT matched by any ignore rule and were safe only by being
un-added):

```
android/build/
android/**/build/
android/.secrets/
android/keystore.properties
**/*.jks
**/*.keystore
*.aab
*.apk
```

`android/AiStroykaWorker/google-services.json` remains **tracked** (pre-existing FCM
config on `main`; not affected by the new rules).
