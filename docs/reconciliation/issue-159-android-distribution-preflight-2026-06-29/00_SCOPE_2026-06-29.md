## Scope

This is an **inspection + docs-only** preflight. It records the current, factual
state of Android release/distribution readiness for the two Android apps
(`AiStroykaManager`, `AiStroykaWorker`) against Google Play requirements.

## What this preflight DID

- Inspected Gradle/module configuration (read-only).
- Inspected application IDs, versions, and SDK levels.
- Inspected signing configuration (key names only, no secret values printed/committed).
- Verified keystore material presence (presence-only).
- Ran unsigned `assembleRelease` / `bundleRelease` build preflights locally
  (build logs written to a local `evidence/` dir that is **not** committed).
- Inspected manifests/permissions for privacy/data-safety surface.
- Inspected Play Console publishing tooling presence.

## What this preflight did NOT do (non-negotiable)

- No upload to Google Play.
- No signing/keystore mutation; no wiring of signing into Gradle.
- No Play Console state mutation.
- No secrets printed or committed (no `.jks`, `keystore.properties`, passwords,
  service account JSON, Play API keys, tokens).
- No APK/AAB/log artifacts committed.
- No deploy, no migrations, no live Supabase data touched, no env changes.
- No iOS changes. No web/app code changes. No workflow changes.
- No readiness claim beyond what the local evidence supports.

## Readiness claims policy

- Google Play readiness, store/distribution readiness, pilot-live, and
  production GA are **NOT** claimed in this preflight.
- Verdicts use `READY` / `BLOCKED` / `OWNER_ACTION_REQUIRED` strictly per evidence.
