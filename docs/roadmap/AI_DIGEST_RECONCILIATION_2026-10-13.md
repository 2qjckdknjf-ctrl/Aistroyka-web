## AIS-RECON-017 Tender Reconciliation

Новый недублирующий продуктовый срез из Scout 6–12 октября; alias источника `AIST-P1-09` относится к этому ID. P1, PLANNED, после AIS-EVID-002 / GRAPH-004 / CORRECTION-009 и текущих pilot gates.

Specification + PDF drawing + existing estimate + optional IFC → source-linked quantity/scope mismatch → Finding Ledger → estimator review. IFC не обязательный prerequisite для небольшого ремонта. Сохранять document/revision/page/element, units/scale, uncertainty, observed difference и dependency on measurement method. 145 м² против 167 м² создаёт NEEDS_REVIEW finding; автоматического изменения сметы нет. После подтверждения отдельный consented adapter может передать commercial revision в ObraPrecio.

AC: contradictory revisions, missing scale/unit, duplicated evidence и unavailable IFC не создают достоверный quantity; human-approved correction versioned, old verdict stale; tenant/customer-finance projection и source access проверены; price impact рассчитывается в ObraPrecio deterministic engine. Никаких shared DB/secrets.

## Infrastructure aware release gate

Уточнение AIS-PILOT-001 через ROMA-ENV-001 / GROW-SCHEDULER-004. P0 до автоматического release verdict, P1 реализация после текущих pilot tasks. Различать code/test failure, CI infrastructure, deployment failure и production failure; confirmed affected provider incident → WAITING_INFRASTRUCTURE, missing correlation → UNKNOWN/BLOCKED. Зелёная status page не заменяет проверки конкретного SHA. После recovery повторить required checks того же/актуального HEAD; changed code/policy/schema делает прошлое evidence stale.
