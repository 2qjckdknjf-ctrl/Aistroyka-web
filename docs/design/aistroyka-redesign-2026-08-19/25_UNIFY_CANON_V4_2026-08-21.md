# Design unify — canon v4 (Memory OS) — 2026-08-21

**Branch:** `design/unify-canon-2026-08-21`  
**Canon:** Memory OS `56263de1-d0a9-48b6-8275-e40df7391f5a` + `docs/design/canonical-renders/2026-08-16/MEMORY_OS_RECORD.md`  
**Visual:** graphite `#0B0F19`, yellow `#F5C518`, Liquid Glass, semantic green/orange/red, dark-only shells

## Goal

Bring web + iOS Manager/Worker + Android Manager/Worker to one coherent v4 system (no competing light chrome, no duplicate project IA, no opaque glass kills).

## Changes

### Web
- Legacy `/projects` and `/projects/[id]` (+ `/ai`) **redirect** to `/dashboard/projects` / Command Center (`?tab=ai`).
- Portfolio “all projects” link → `/dashboard/projects`.
- `Card` → Liquid Glass `.card` / `.card-elevated` CSS; `CARD` tokens updated.
- Platform admin header → `surface-glass-chrome`; inactive nav → `surface-glass-muted`.
- Removed opaque `bg-aistroyka-surface*` overrides on `DashboardGlassCard` (portfolio, intelligence, AI guide, admin AI runtime).

### iOS
- Shared `AistroykaViewChrome` helpers (`aistroykaPageBackground` / `aistroykaListChrome` / `aistroykaFormChrome`).
- Manager + Worker Lists/Forms: hide system scroll fill, graphite page, muted row surfaces.
- Yellow CTAs use graphite `onPrimary`; TaskChat bubbles use canon surfaces.
- Filter chips / KPI / onboarding / home already on semantic colors.

### Android
- Themes: dark-only `MaterialComponents.NoActionBar`, `colorOnPrimary`, light status/nav icons off, forceDarkAllowed false.
- Semantic `success()` / `warning()` wired into Worker/Manager success and changes-requested feedback (no yellow-as-success).

## Still deferred
- Full UIKit-parity Liquid Glass blur materials on every mobile card (needs platform glass primitive beyond flat muted fills).
- Migrating remaining `bg-aistroyka-surface*` control chrome (chips/hover) to glass-only — intentional for density/readability on dense tables.
- Deleting unused legacy `/projects/*` component modules (kept as import sources for Command Center panels).
