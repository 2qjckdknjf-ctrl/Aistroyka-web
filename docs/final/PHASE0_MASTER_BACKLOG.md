# Phase 0 — Мастер-бэклог (группировка P0–P3)

**Дата:** 2026-03-23  
**Принцип:** пункты основаны на структуре репо, наличии миграций/маршрутов и **пробелах** текущего аудита; статусы «сделано» не присваиваются без проверки сценарием или тестом.

---

## P0 — блокеры релиза и безопасности

| ID | Тема | Описание | Доказательство закрытия |
|----|------|----------|-------------------------|
| P0-01 | Миграции ↔ среда | Подтвердить, что целевая БД соответствует последним миграциям в `apps/web/supabase/migrations/` | Лог apply + выборочная сверка схемы |
| P0-02 | Критичные регрессии auth/tenant | Любой дефект, ломающий изоляцию тенантов или сессию | Тесты + ручной смоук + ревью RLS |
| P0-03 | Сборка релиза | Стабильный зелёный `npm run build` (и зафиксированный CI job) | Артефакт CI / запись в validation report |
| P0-04 | Потеря лидов | Контакт/демо не сохраняется или не виден оператору | E2E форма → БД → admin/leads |
| P0-05 | Деплой: единая правда | Явно определить primary target (CF/OpenNext vs Vercel) для production web | Документ + workflow |
| P0-06 | Секреты и ENV | Нет утечек; `.env.example` и `docs/ENVIRONMENT-VARIABLES.md` согласованы с кодом | Ревью + скрипт verify где есть |

## P1 — закрытие перед расширением (Closure A/B)

| ID | Тема | Описание | Доказательство |
|----|------|----------|----------------|
