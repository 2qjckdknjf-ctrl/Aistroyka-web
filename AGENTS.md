Stale remote branch deletion follows dry-run manifest → owner approval → annotated archive tags `archive/<branch>/<date>` before delete → docs-only execution report PR with non-author APPROVED merge; never delete open-PR, dangerous, manual-review, or `cursor/aistroyka-system-maturity-7957` branches.

## Learned Workspace Facts

- Aistroyka is a monorepo; web application lives in apps/web (Next.js, App Router).
- Root build: from repo root run `bun install --frozen-lockfile` (Bun **1.2.15**, see `.tool-versions`) and `bun run build` (builds packages/contracts then apps/web). Canonical lock: root `bun.lock` only; root `package-lock.json` is for Vercel npm preview — validate with `node scripts/ci/validate-npm-lock.cjs`; do not commit `package-lock.json` on bun-only changes. Security headers: single source `apps/web/lib/security-headers.ts` via middleware; smoke `bash scripts/smoke/security_headers.sh`.
- Production runtime and DNS ownership is **Cloudflare Workers** (`apps/web/wrangler.toml`, OpenNext); use `bun run cf:build` then Wrangler deploy, and verify apex/www routes through Cloudflare when making production readiness claims. **Canonical production domain is `aistroyka.ai`** (including `www.aistroyka.ai`); staging is **`staging.aistroyka.ai`**—confirm deploy via `GET /api/v1/health` → `buildStamp.sha7`. `aistroyka.com` and `www.aistroyka.com` are redirect-only entry domains (301 to `https://aistroyka.ai`, preserving path and query)—do not serve the app independently from `.com`. Do not run `bun run build` and `bun run cf:build` in parallel—concurrent Next/OpenNext work can corrupt `apps/web/.next`; run sequentially or remove `apps/web/.next` before retrying. Web UI is App Router under `apps/web/app` (no `pages/` tree); root-level error UI uses `app/global-error.tsx`—reintroducing `pages/*` (for example a custom 500 page) can destabilize standalone or OpenNext builds, so validate with `cf:build` before relying on it. **AI runtime is `apps/web` only** (no repo Python `backend/`); canonical live gate `bash scripts/smoke/ai_live_provider.sh --require-live`; supplementary smokes `scripts/smoke/ai_*.sh`; architecture truth in `docs/ai/AUDIT_AI_RUNTIME_ARCHITECTURE_TRUTH.md`.
